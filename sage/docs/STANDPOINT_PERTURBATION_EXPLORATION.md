# Exploration: maintained orientation vs goal reactivation (Standpoint Perturbation Test)

**Date:** 2026-10-21
**Status:** Research proposal; not implemented; no claim about subjective experience
**Origin:** Daniel H. Lange's LinkedIn question concerning Sprout and *The Standpoint Threshold: Architectural Conditions for Processing from Somewhere* (2026), https://doi.org/10.3390/philosophies11040125

## Hypothesis and boundary
SAGE beings can show persistence caused by external orchestration (e.g., closed todos re-fed on wake). The stronger test is whether an internally maintained **orientation** changes relevance/perception, candidate plans, actions, and resulting updates across discontinuous inference, over and above equivalent stored goals and prompt scaffolding.

Disaggregate:
- **record persistence:** same task reconstructed from logs/todos;
- **orientation persistence:** a maintained, revisable interpretation of ambiguous circumstances;
- **closed-loop operativity:** orientation causally mediates multiple functions and is itself affected by observed outcomes.

Treat 'being' as a candidate composite cognitive system: resident local SAGE + cognition + sensors/effectors. Do not assume the individual model pass alone must contain all continuity. Compare visitor roles separately: remote opaque contexts complicate attribution and possible leakage.

## Proposed protocol (exploratory before preregistration)
1. **Audit wake inputs** and instrument todo lifecycle including closed items, memory retrievals, primer/identity, context assembly, observations and action authorization. Establish repeated-goal baseline and prompt-echo negative controls.
2. **Create matched ambiguous settings** where two defensible orientations A/B can emerge through normal experience, not a command to 'adopt orientation A/B'. Predefine behavioral/readout signatures using relevance selection, alternative generation, planned tasks, actual authorized actions and later memory update.
3. **Matched perturbation:** provide new observations/evidence to A, B and neutral baseline; track whether their trajectories diverge coherently, update appropriately, and converge when evidence is decisive. Include contradictory feedback.
4. **Ablations:** remove or mask todo refeeding, episodic retrieval, identity primer and summarized goal state separately; preserve safety controls. Avoid altering more than one variable at a time.
5. **Controls/replication:** equalize observable context, task state, tool access, model/checkpoint, stochastic settings and resources; repeated seeds and runs. Instrument hidden state limits. Compare residents across hardware/model sizes, optionally visitors only with explicit upstream opacity caveat.
6. **Analysis:** test whether prior orientation predicts perception/planning/action conditional on current text and records; look for cross-function coupling, evidence-sensitive revision and feedback-mediated next-wake change. Log counterexamples.

## Failure criteria and cautions
- Merely restating first-person identity, goal, or a preferred framing is not sufficient.
- Longitudinal persistence by repeated task injection is not evidence of internal orientation.
- Apparent A/B effects eliminated by matching prompt/retrieval inputs do not establish a stronger standpoint.
- System-level causes should not be misattributed to model-internal latent state.
- Strong evidence of functional standpoint is **not** proof of phenomenal consciousness or personhood.
- Preserve governance gate checks and avoid using action tests to grant new permissions.

## Outputs
- Protocol and instrumentation manifest (wake trace, inputs, retrieved memories, goal lifecycle, action evidence, feedback).
- Matched A/B/baseline traces with seed/config metadata.
- Ablation results and null findings alongside successes.
- A reviewable report of what was demonstrated, what's infrastructural, and what remains underdetermined.
